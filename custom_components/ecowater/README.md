# 怡口软水机 (Ecowater China) Home Assistant 集成

将国内版怡口软水机（609ECM 等型号）接入 Home Assistant，以「怡口软水机」设备卡片形式展示与控制设备。

## 功能特性

- **36 个实体**：信息类（传感器）、设置类（数字/选择/开关/文本）、操作类（按钮）
- **token 自动刷新**：用微信 openid 自动获取/刷新 token，永不过期
- **设备卡片**：所有实体关联到统一的「怡口软水机」设备
- **60 秒自动刷新**：云端轮询

### 实体清单

| 类别 | 实体 |
|---|---|
| 信息 | 信号强度、剩余盐量、距下次再生可用水量、本日用水总量、即时流量、再生次数、故障状态、本日/近7日/本月/本年的用水总量与平均用水、设备型号、产品序列号、在线状态 |
| 设置 | 总硬度、盐位、再生模式、再生时间、再生最大间隔、低盐警报、时间制式、容积单位、硬度单位、长时间出水提示、警报通知、低温/长时间出水/低盐/软水用尽警报、OTA自动升级、设备命名 |
| 操作 | 立即再生、设备自检 |

## 安装

### 方式一：HACS（推荐）

1. HACS → 自定义存储库 → 添加本仓库（类别：集成）
2. 安装「怡口软水机 (Ecowater China)」
3. 重启 Home Assistant

### 方式二：手动安装

1. 将 `custom_components/ecowater/` 目录复制到 HA 配置目录的 `custom_components/` 下
2. 重启 Home Assistant

## 配置

1. 设置 → 设备与服务 → 添加集成 → 搜索「怡口」
2. 输入设备 **MAC**、**openid**、**手机号**（可选：设备 IP、设备 Web 界面密码）
3. 提交（会自动验证连接）

## 如何获取参数

| 参数 | 说明 |
|---|---|
| MAC | 设备 MAC 地址（无冒号大写），抓包获取 |
| openid | 微信 openid（固定标识，用于自动获取 token），抓包获取 |
| 手机号 | 绑定设备的注册手机号 |
| 设备 IP | 设备 Web 界面 IP（配网/信号强度用，默认 192.168.31.36） |
| 设备密码 | 设备 Web 界面密码（默认留空用通用密码） |

抓包方式：微信 PC 版小程序走系统代理 + mitmproxy，`openid` 在 `customer/getCustomer` 请求体或 `customer/openid` 响应中获取。

## 数据源说明

| 服务器 | 用途 |
|---|---|
| `iot2.chinaecowater.com` | 云 API（盐量/水量/再生状态等业务数据） |
| 设备本体（`192.168.31.36`） | WiFi 模块本地后台（配网/信号强度） |

## 字段映射（dataXX → 界面）

| dataXX | 含义 |
|---|---|
| data23 | 距下次再生可用水量（L） |
| data13 | 剩余盐量（天） |
| data15 | 再生次数（次） |
| data1D | 本日用水总量（L） |
| data1C | 即时流量（L/min） |
| data1E | 总硬度（÷1.71 = 格令） |
| data25 | 再生时间（时×256+分） |
| data2A | 盐位 |
| data31 | 低盐警报（天） |
| fault | 故障（null=正常） |
| isUpgrade | OTA 开关 |

## 注意事项

- **token 自动刷新**：用 openid 自动获取/刷新 token，永不过期
- 本集成适配**国内版**怡口（`iot2.chinaecowater.com`），不适用国外版（Ayla IoT / iQua）
